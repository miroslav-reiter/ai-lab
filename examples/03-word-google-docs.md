# 📄 Laboratórne cvičenie 3 – Word a Google Dokumenty

**Cieľ:** Použiť Word Add-in a Writing Report v Google Dokumentoch.

**Vstup:** Vlastný testovací dokument s textom dlhším ako 250 znakov.

**Word – postup:**
1. Home → Add-ins → More Add-ins → GPTZero → Add.
2. Home → Show GPTZero.
3. Označíme text a klikneme Get Results.
4. Zaznamenáme klasifikáciu.

**Google Docs – postup:**
1. Vytvoríme nový vlastný dokument.
2. Postupne napíšeme niekoľko viet, upravíme ich a vložíme pripravený odsek.
3. S prihláseným rozšírením a oprávnením editovať vyberieme Watch Writing Report.
4. Porovnáme záznamy postupného písania a vkladania.

**Čo to robí:** Porovnáva analýzu textu a analýzu procesu.

**Vysvetlenie:** Vloženie textu nie je dôkaz plagiátu a Writing Replay nepotvrdzuje identitu osoby.

**Očakávaný výstup:** Dve samostatné pozorovania s limitmi a dátumom testu.

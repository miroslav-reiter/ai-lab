# 🛡️ GPTZero – metodika auditu, ochrana súkromia a zodpovedné používanie

Podklady pre lektorov, pedagógov, výskumníkov, doktorandov, znalcov, HR a organizácie.

## 📌 Čo je a čo nie je dôkaz

**AI detektor je nástroj na získanie indície.** Výsledok by nemal automaticky viesť k obvineniu, sankcii ani verejnému označeniu autora za nečestného.

| Otázka | Vhodný ďalší krok |
|---|---|
| GPTZero označil text ako AI | kontrola metodiky, rozsahu a samotného textu |
| GPTZero označil text ako Human | nevyhlasovať, že AI určite nebola použitá |
| Zistili sme podobnosť s publikáciou | otvoriť zdroj a skontrolovať citáciu |
| Zaznamenali sme veľký paste event | zistiť pôvod vkladaného obsahu |
| Chýba dokumentová história | priznať neúplnosť dôkazov |
| Existuje podozrenie na nepravdivú citáciu | overiť publikáciu, DOI a zhodu tvrdenia |

## 🧾 Šablóna auditnej karty

| Pole | Záznam |
|---|---|
| ID dokumentu | anonymizovaný identifikátor |
| Jazyk a počet slov | údaj o vzorke |
| Pôvod materiálu | vlastný / súhlas autora / iný oprávnený základ |
| Čas skenu | dátum a čas |
| Režim a plán | Basic / Advanced / ďalšie nástroje |
| Výsledok | Human / AI / Mixed / Uncertain |
| Miera istoty | iba ak je zobrazená, s kontextom |
| Podobnosť a zdroje | konkrétne overené zhody |
| Writing Replay | dostupný/nedostupný, rozsah záznamu |
| Nezávislé podklady | pracovné súbory, verzovanie, komunikácia |
| Predbežné závery | indície, nie konečná vina |
| Zodpovedná osoba | kontrolór s oprávnením |
| Lehota uchovania | podľa pravidiel organizácie |

## 🔐 Osobné údaje a dôvernosť

1. Do online detektorov nevkladáme citlivé cudzie dokumenty bez oprávnenia.
2. Pri študentských prácach preveríme GDPR, pravidlá školy a podmienky poskytovateľa.
3. Rozlišujeme medzi webovým skenom, doplnkom a Writing Replay, ktoré môžu spracúvať odlišné druhy údajov.
4. Preferujeme anonymizované materiály a minimálny rozsah.
5. Ak je dostupné zdieľanie Writing Report linkom, kontrolujeme prístupové práva.
6. Do verejného GitHubu nikdy neukladáme skutočné študentské práce ani osobné spisy.

## 🧠 Praktické cvičenie – odborný záver

### **1. Práca s výsledkom „Likely AI“**

**Postup:** Dostaneme testovací výstup GPTZero, overíme známy pôvod vzorky, ďalšie indície a napíšeme vecné hodnotenie.

**Čo to robí:** Trénuje presné vyjadrovanie neurčitosti.

**Vysvetlenie:** Správne znenie napríklad je „Detektor klasifikoval text ako pravdepodobne AI. Tento výsledok samostatne nepreukazuje autorstvo ani porušenie pravidiel.“

### **2. Kontrola potenciálneho plagiátu**

**Postup:** Otvoríme nájdený zdroj a posúdime úvodzovky, uvedenie autora, parafrázu a bibliografiu.

**Čo to robí:** Oddeľuje textovú podobnosť od etického hodnotenia.

**Vysvetlenie:** Riadne citovaná veta môže mať doslovnú zhodu s originálom.

### **3. Analýza verejného príspevku**

**Postup:** Na vlastnom sociálnom príspevku vyskúšame AI Vision a zapíšeme len technický výsledok.

**Čo to robí:** Učí rešpektovať obmedzenia detekcie.

**Vysvetlenie:** Nepriraďujeme verejnej osobe nálepku klamára ani podvodníka.
